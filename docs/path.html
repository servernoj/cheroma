Quintic Easing – Peak Velocity Derivation

1. The easing function

Normalized position as a function of normalized time $\tau \in [0,1]$:

$$s(\tau) = 10\,\tau^3 - 15\,\tau^4 + 6\,\tau^5$$

This satisfies $s(0)=0$, $s(1)=1$, and has zero first and second derivatives at both endpoints.

2. Normalized velocity

Differentiate with respect to $\tau$:

$$s'(\tau) = 30\,\tau^2 - 60\,\tau^3 + 30\,\tau^4 = 30\,\tau^2(1-\tau)^2$$

3. Finding the peak

Set $s''(\tau) = 0$:

$$s''(\tau) = 60\,\tau\,(1-\tau)(1-2\tau) = 0 \quad\Longrightarrow\quad \tau = 0,\;\tfrac{1}{2},\;1$$

Evaluate at the interior critical point $\tau = \tfrac{1}{2}$:

$$s'\!\left(\tfrac{1}{2}\right) = 30 \cdot \frac{1}{4} \cdot \frac{1}{4} = \frac{30}{16} = \frac{15}{8} = 1.875$$

4. Real-units velocity

Let $\Delta$ be the total angular displacement and $T$ the total traversal time. Real position is:

$$\theta(t) = \theta_{\text{from}} + s\!\left(\frac{t}{T}\right)\,\Delta$$

So real velocity is:

$$v(t) = \frac{\Delta}{T}\;s'\!\left(\frac{t}{T}\right)$$

Peak real velocity:

$$v_{\text{peak}} = \frac{\Delta}{T} \cdot \frac{15}{8}$$

5. The bug in the current code

The current planner sets the total time as if average speed equals $v_{\max}$:

$$T_{\text{current}} = \frac{\Delta}{v_{\max}}$$

Substituting into the peak-velocity expression:

$$v_{\text{peak}} = \frac{\Delta}{\;\Delta / v_{\max}\;} \cdot \frac{15}{8} = \frac{15}{8}\,v_{\max} \approx 1.875\,v_{\max}$$

The arm moves 87.5 % faster than intended at mid-trajectory.

6. Corrected duration

To enforce $v_{\text{peak}} = v_{\max}$, solve for $T$:

$$v_{\max} = \frac{\Delta}{T} \cdot \frac{15}{8} \quad\Longrightarrow\quad T_{\text{corrected}} = \frac{15}{8} \cdot \frac{\Delta}{v_{\max}}$$

Number of waypoints at cadence $\delta t$:

$$N = \left\lceil \frac{T_{\text{corrected}}}{\delta t} \right\rceil + 1 = \left\lceil \frac{15\,\Delta}{8\,v_{\max}\,\delta t} \right\rceil + 1$$

7. Why no numerical integration is needed

The easing function $s(\tau)$ is the closed-form integral of the velocity profile. Evaluating it at uniformly spaced $\tau_i = \frac{i}{N-1}$ is identical to stepping through time at fixed $\delta t$ and reading off position from the already-integrated curve.

For any normalized easing where $\displaystyle\int_0^1 s'(\tau)\,d\tau = 1$, the average normalized speed is $1$ and the peak-to-average ratio is simply $\max\!\big(s'(\tau)\big)$. That ratio is a constant of the curve shape — independent of $\Delta$ or $v_{\max}$ — and can be precomputed once.
