FK/IK Simple Reference (4‑DOF: yaw + 3 pitch)

This page is a minimal reference for the forward kinematics used in the main document, plus the common simplification when the tool pitch is constrained to \(\gamma=180^\circ\) (\(\gamma=\pi\)).

Definitions

  • Joint angles: \(q_0\) = base yaw; \(q_1,q_2,q_3\) = shoulder/elbow/wrist pitch (parallel axes).
  • Link lengths: \(H\) (shoulder axis height), \(L_1,L_2,L_3\).
  • \(r\): horizontal (radial) distance from base axis to TCP in the arm plane.
  • Tool pitch in the arm plane: \(\gamma = q_1+q_2+q_3\).

Use radians in \(\sin(\cdot),\cos(\cdot)\). (If you store angles in degrees, convert before trig.)

Forward kinematics (general \(\gamma\))

Planar (in the rotated arm plane):

\[ r = L_1\sin(q_1) + L_2\sin(q_1+q_2) + L_3\sin(q_1+q_2+q_3) \]

\[ z = H + L_1\cos(q_1) + L_2\cos(q_1+q_2) + L_3\cos(q_1+q_2+q_3) \]

Rotate by base yaw to world coordinates:

\[ x = r\cos(q_0),\qquad y = r\sin(q_0) \]

FK with constrained tool pitch \(\gamma=180^\circ\) (\(\gamma=\pi\))

If you enforce \(\gamma=q_1+q_2+q_3=\pi\), then \(\sin(\gamma)=0\) and \(\cos(\gamma)=-1\), so the last link contributes only a constant height shift \(-L_3\) and no radial reach.

\[ r = L_1\sin(q_1) + L_2\sin(q_1+q_2) \]

\[ z = H - L_3 + L_1\cos(q_1) + L_2\cos(q_1+q_2) \]

And still:

\[ x = r\cos(q_0),\qquad y = r\sin(q_0) \]

Inverse kinematics (IK) — step by step (assume \(\gamma=\pi\))

Assumptions for this derivation: you already solved base yaw \(q_0\) from \((x,y)\), you reduced the problem to the arm plane, and you constrain the tool pitch to \(\gamma=q_1+q_2+q_3=\pi\) (so \(q_3=\pi-q_1-q_2\)). The remaining unknowns are \(q_1,q_2\).

1) Reduce 3D target \((x,y,z)\) to planar target \((r, z_2)\)

From the world position \((x,y)\), compute base yaw and radial distance:

\[ q_0 = \operatorname{atan2}(y,x),\qquad r=\sqrt{x^2+y^2} \]

Under \(\gamma=\pi\), the FK becomes:

\[ r = L_1\sin(q_1) + L_2\sin(q_1+q_2) \]

\[ z = H - L_3 + L_1\cos(q_1) + L_2\cos(q_1+q_2) \]

Move known constants to the left by defining:

\[ z_2 = z - H + L_3 \]

Then the planar 2-link equations are:

\[ r = L_1\sin(q_1) + L_2\sin(q_1+q_2),\qquad z_2 = L_1\cos(q_1) + L_2\cos(q_1+q_2) \]

2) Solve for \(q_2\) using the law of cosines

Consider the triangle formed by link lengths \(L_1\), \(L_2\), and the distance from shoulder to the “wrist point” \(\rho = \sqrt{r^2+z_2^2}\). By the law of cosines:

\[ \rho^2 = L_1^2 + L_2^2 + 2L_1L_2\cos(q_2) \]

Rearranging gives:

\[ D = \cos(q_2) = \frac{r^2+z_2^2 - L_1^2 - L_2^2}{2L_1L_2} \]

Reachability requires \(|D|\le 1\). Then there are two elbow branches:

\[ q_2 = \operatorname{atan2}\left(\pm\sqrt{1-D^2},\,D\right) \]

If you must avoid the “elbow-down” configuration, do not hardcode the \(\pm\) sign. Instead, evaluate both candidates and keep only the one that satisfies your constraint (e.g., elbow stays above the table).

A practical elbow-up selection rule:

  • Compute both candidates \(q_{2+}=\operatorname{atan2}(+\sqrt{1-D^2},D)\) and \(q_{2-}=\operatorname{atan2}(-\sqrt{1-D^2},D)\).
  • For each candidate, compute \(q_1\) (step 3 below), then compute the elbow height: \[ z_{\text{elbow}} = H + L_1\cos(q_1) \]
  • Keep the solution with larger \(z_{\text{elbow}}\), or reject any solution with \(z_{\text{elbow}}\) below a clearance threshold.

3) Solve for \(q_1\) by splitting the planar angle into two parts

Define the direction from the shoulder to the wrist point in the \((r,z_2)\) plane:

\[ \alpha = \operatorname{atan2}(r, z_2) \]

Define the internal “link angle”:

\[ \beta = \operatorname{atan2}\left(L_2\sin(q_2),\,L_1 + L_2\cos(q_2)\right) \]

Then:

\[ q_1 = \alpha - \beta \]

4) Recover \(q_3\) from the pitch constraint

\[ q_3 = \pi - q_1 - q_2 \]

Finally, check joint limits and prefer a consistent elbow branch to avoid sudden flips during motion.
