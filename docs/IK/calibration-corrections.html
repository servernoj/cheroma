Calibration: keep calPoints, fit small correction factors

Your current code uses piecewise linear interpolation (calPoints) to map angle→pulse. This page shows how to add a small per-servo correction layer that can be fitted from 20–50 measurements using LM/LMS, without replacing interpolation with a single linear \(q=k\,u+b\) model.

Current setup (what stays the same)

  • FK/IK operate on physical joint angles \(q\) (right-hand rule, degrees or radians).
  • Servo output is a pulse width \(p\) (µs) computed by interpolating a calibrated table calPoints.
  • calPoints is a per-servo array of \([angle, pulse]\) pairs and can have any length \(\ge 2\).
We keep your interpolation as-is. Calibration adds a small adjustable layer in front of it.

Correction model: \((a,b)\) per servo

The core idea is to separate: (1) a nominal actuator curve defined by calPoints, and (2) a small correction that accounts for mounting offsets and small scale errors.

Table angle vs physical angle

Let \(q^{des}\) be the desired physical joint angle produced by IK. Before looking up a pulse in calPoints, convert it to a “table-angle” \(q^{tbl}\):

\[ q^{tbl} = \frac{q^{des} - b}{a} \]

  • \(a\) is a scale (unitless), typically close to 1
  • \(b\) is an offset (degrees), typically a few degrees
This is equivalent to modeling the realized physical angle as: \[ q^{phys} \approx a\,q^{cmd} + b \] but for control we use the inverse form \(q^{tbl}=(q^{des}-b)/a\) so we can still query the table.

Why this works with piecewise interpolation

Your mapping from angle to pulse is a function \(p = f(q)\) defined by interpolation of calPoints. With the correction layer, you command:

\[ p = f(q^{tbl}) = f\!\left(\frac{q^{des}-b}{a}\right) \]

This keeps the actuator nonlinearity in \(f(\cdot)\) and only fits small, smooth corrections \((a,b)\).

Runtime flow (IK → corrected table-angle → calPoints → pulse)

  1. IK computes desired physical joint angles \(q^{des}\).
  2. Correction per servo: compute \(q^{tbl}=(q^{des}-b)/a\).
  3. Interpolation: compute pulse \(p=f(q^{tbl})\) using your existing sorted calPoints interpolation.
  4. Driver: send \(p\) to PCA9685.
Start by fitting offsets only: set \(a=1\) for all servos and fit only \(b\). Add \(a\) parameters only if you still see systematic scaling error across the full range.

20–50 measurement fitting flow (LM/LMS)

Collect \(N\) calibration samples. Each sample \(i\) must record:

  • \(q^{cmd}_i\): the commanded joint angles you asked the robot to go to (deg).
  • \(x^{meas}_i\in\mathbb{R}^3\): the measured TCP position \([x,y,z]\) in the base/world frame (mm).

Prediction model used in the fit

For a candidate parameter vector \(P\) that contains per-servo \((a_j,b_j)\) (and optionally small segment corrections), predict the physical angles that actually occurred:

\[ q^{phys}_{i,j}(P) = a_j\,q^{cmd}_{i,j} + b_j \]

Then run forward kinematics:

\[ x^{pred}_i(P) = FK\!\left(q^{phys}_i(P);\;H,L_1,L_2,L_3,dX,\ldots\right) \]

Residual:

\[ r_i(P) = x^{pred}_i(P) - x^{meas}_i \]

Solve:

\[ P^\* = \arg\min_P \sum_{i=1}^{N}\lVert r_i(P)\rVert^2 \]

This calibration happens at the model level (angles → FK → position). It does not require you to change your interpolation code. After you fit \(a,b\), you apply them at runtime as \(q^{tbl}=(q^{des}-b)/a\).

How to persist the outcome

Keep your existing calPoints, and add: 

"angleCorrection": {
  "scale": 1.0,
  "offset": 0.0
}

Example (per servo): 

"shoulder": {
  "channel": 1,
  "calPoints": [[-90,2190],[0,1550],[90,880]],
  "home": 0,
  "kinematics": "q1",
  "angleCorrection": { "scale": 0.992, "offset": -1.7 }
}
Suggested fitting stages:
  1. Fit only offsets \(b_j\) (set all \(a_j=1\)).
  2. If needed, unlock scales \(a_j\) afterwards.
  3. Only then consider fitting segment lengths or \(dX\) if errors remain systematic.
