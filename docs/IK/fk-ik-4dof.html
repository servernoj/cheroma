Definitions & conventions

Geometry

  • \(H\): height of the shoulder pitch axis above the base yaw axis origin.
  • \(L_1\): shoulder→elbow length.
  • \(L_2\): elbow→wrist pitch axis length.
  • \(L_3\): wrist→TCP length (includes gripper extension; use an “effective” \(L_3\)).

World / base frame

  • Origin at base yaw axis on the table.
  • \(+Z\) is up.
  • At base yaw \(q_0=0\), the arm reaches along \(+X\) (toward higher ranks / farther side of board).
  • \(+Y\) points along files A→H (left→right when looking from the base toward the board).

Joint angles

  • \(q_0\): base yaw (about \(+Z\)).
  • \(q_1,q_2,q_3\): shoulder / elbow / wrist pitch (parallel axes, planar after yaw).
“Zero” pose per your servo neutrals: \(q_1=0\Rightarrow L_1\) points up (\(+Z\)); \(q_2=0\Rightarrow L_2\) collinear with \(L_1\); \(q_3=0\Rightarrow L_3\) collinear with \(L_2\).

Define the in‑plane tool pitch angle (direction of \(L_3\) measured from +Z in the arm plane): \[ \gamma = q_1 + q_2 + q_3 \]

Servo pulse → joint angle mapping (handles reversed direction)

FK/IK are defined in terms of physical joint angles \(q\) (right‑hand rule). Separately, you need an actuator mapping between servo pulses \(p\) and those physical angles.

Simple linear model around 1.5 ms neutral

Let \(p_i\) be the servo pulse width in milliseconds and \(p_0=1.5\,\text{ms}\) be neutral. A common mapping is:

\[ q_i = k \, (p_i - p_0) + q_{trim,i} \]

  • \(k\): slope (radians per millisecond). It can be positive or negative depending on servo mounting direction.
  • If 1.0 ms ↔ −90° and 2.0 ms ↔ +90°, then \(k=\pi\) rad/ms (positive slope).
  • \(q_{trim,i}\): small calibration offset (fine‑tune “true zero”)

Recommended persistence: store physical angles in cal_points (no sign)

For clarity and to match common robotics conventions, we recommend storing calibration tables in the physical joint angle frame (right‑hand rule angles used by FK/IK). In this convention you do not store a separate sign and you do not need \(s_i\) in the mapping above. The “direction inversion” is simply reflected by the fact that pulses may decrease as the physical angle increases.

Example: if a shoulder joint physically reaches \(+90^\circ\) at 880 µs and \(-90^\circ\) at 2190 µs, then cal_points should store exactly those physical angles: 
"shoulder": {
  "channel": 1,
  "cal_points": [
    [-90.0, 2190],
    [0.0, 1550],
    [90.0, 880]
  ]
}

Forward kinematics (FK)

Compute the end-effector position \( (x,y,z) \) from joint angles \(q_0,q_1,q_2,q_3\). The arm is planar in a vertical plane that is rotated by \(q_0\) around \(Z\).

Planar reach and height

Let \(r\) be the horizontal (radial) distance from the base axis to the TCP. With \(q=0\) meaning “up” (\(+Z\)):

\[ r = L_1\sin(q_1) + L_2\sin(q_1+q_2) + L_3\sin(q_1+q_2+q_3) \]

\[ z = H + L_1\cos(q_1) + L_2\cos(q_1+q_2) + L_3\cos(q_1+q_2+q_3) \]

Rotate the plane by base yaw

\[ x = r\cos(q_0),\qquad y = r\sin(q_0) \]

The in‑plane tool pitch is \(\gamma=q_1+q_2+q_3\). Later, when you add wrist roll, you’ll get yaw‑plane tool direction + a roll DOF.

Inverse kinematics (IK) for \((x,y,z)\) + tool pitch

Solve for \(q_0,q_1,q_2,q_3\) given a desired TCP position \((x,y,z)\) in the base frame and a desired in‑plane tool pitch \(\gamma\). This matches your goal: keep the gripper pitched “down toward the board” while moving to a square.

Step 1 — base yaw and radial distance

\[ q_0 = \operatorname{atan2}(y,x),\qquad r = \sqrt{x^2+y^2} \]

Step 2 — reduce to a 2‑link problem by removing \(L_3\)

Work in the rotated arm plane coordinates \((r, z')\) where \(z' = z - H\). If the last link \(L_3\) is constrained to pitch \(\gamma\), the wrist point \((r_w, z_w)\) is:

\[ r_w = r - L_3\sin(\gamma),\qquad z_w = (z - H) - L_3\cos(\gamma) \]

Step 3 — 2‑link IK for \(q_1,q_2\)

Define:

\[ D=\frac{r_w^2+z_w^2 - L_1^2 - L_2^2}{2L_1L_2} \]

Reachability condition: \(|D|\le 1\). If not, the target is out of reach for the chosen \(\gamma\) (or due to joint limits).

\[ q_2 = \operatorname{atan2}\left(\pm\sqrt{1-D^2},\,D\right) \]

The \(\pm\) selects elbow‑up vs elbow‑down. For chess moves, you’ll usually pick the branch that avoids the table and avoids self-collision.

\[ q_1 = \operatorname{atan2}(r_w, z_w)\;-\; \operatorname{atan2}\left(L_2\sin q_2,\; L_1 + L_2\cos q_2\right) \]

Step 4 — wrist pitch

\[ q_3 = \gamma - q_1 - q_2 \]

Joint limits
Clamp/check \(q_1,q_2,q_3\) to your actual servo range (often around \(\pm 90^\circ\) from neutral, but mechanical limits may be tighter).
“Gripper down” pitch
Depending on how your gripper is mounted, “down toward the board” may correspond to \(\gamma\approx \pi\), \(\gamma\approx 0\), or \(\gamma\approx\) (some constant offset). If the gripper is rigidly attached, you can encode this as a fixed offset \(\gamma = \gamma_{down} + \gamma_{task}\).

Implementation skeleton

# Inputs: x,y,z (mm), gamma (rad), H,L1,L2,L3 (mm)
# Output: q0,q1,q2,q3 (rad) for one IK branch

q0 = atan2(y, x)
r  = sqrt(x*x + y*y)

rw = r - L3*sin(gamma)
zw = (z - H) - L3*cos(gamma)

D  = (rw*rw + zw*zw - L1*L1 - L2*L2) / (2*L1*L2)

# if abs(D) > 1: unreachable

q2 = atan2(+sqrt(1 - D*D), D)   # elbow-down branch; use -sqrt(...) for other branch
q1 = atan2(rw, zw) - atan2(L2*sin(q2), L1 + L2*cos(q2))
q3 = gamma - q1 - q2

Keeping a pen vertical + last motion straight down

Use this when you want the tool (pen / gripper approach) to stay at a fixed \((x,y)\) while you move only \(z\) for the final touch. The idea is: keep base yaw \(q_0\) fixed, keep tool pitch \(\gamma\) fixed, and re-solve the planar IK for different heights.

1) Choose the “vertical down” pitch \(\gamma_{down}\)

In this document’s convention, \(\gamma\) is measured from \(+Z\) in the arm plane. If your tool axis is aligned with the direction of \(L_3\), then:

  • tool up (\(+Z\)) corresponds to \(\gamma = 0^\circ\)
  • tool down (\(-Z\)) corresponds to \(\gamma = 180^\circ\)
With typical hobby servos limited to about \(\pm 90^\circ\) per joint, \(\gamma \approx 180^\circ\) may be unreachable without a mounting offset. In practice you often use \(\gamma_{down} = 180^\circ + \gamma_{mount}\) (a fixed constant) and/or accept a slightly tilted tool.

2) Hold \((x,y)\) constant by holding \(q_0\) and \(r\) constant

For a target \((x,y)\) in the base frame:

\[ q_0 = \operatorname{atan2}(y,x),\qquad r=\sqrt{x^2+y^2} \]

During the final “straight down” move, keep \(q_0\) fixed and keep \((x,y)\) fixed (so \(r\) is fixed). Only \(z\) changes.

3) For each height \(z\), re-solve IK with fixed \(\gamma=\gamma_{down}\)

Use the same wrist-point reduction as in the main IK section:

\[ r_w = r - L_3\sin(\gamma),\qquad z_w = (z - H) - L_3\cos(\gamma) \]

Then solve the 2-link IK for \(q_1,q_2\), and compute \(q_3\) from \(\gamma\):

\[ D=\frac{r_w^2+z_w^2 - L_1^2 - L_2^2}{2L_1L_2} \]

\[ q_2 = \operatorname{atan2}\left(\pm\sqrt{1-D^2},\,D\right) \]

\[ q_1 = \operatorname{atan2}(r_w, z_w)\;-\; \operatorname{atan2}\left(L_2\sin q_2,\; L_1 + L_2\cos q_2\right) \]

\[ q_3 = \gamma - q_1 - q_2 \]

To avoid sudden “elbow flips” during the descent, pick an elbow branch (the \(\pm\)) at the approach height and keep the same branch for all intermediate \(z\).

4) Practical execution pattern

  • Approach: solve IK at \((x,y,z_{high},\gamma_{down})\) and move there.
  • Touch: solve IK at \((x,y,z_{touch},\gamma_{down})\) and move there (only \(z\) changes).
  • Retract: return to \(z_{high}\) before moving laterally to another square.

Notes for chessboard usage

  • Square → target: treat each square center as a fixed \((x,y)\) on the board plane, plus a small \(z\) for approach and a lower \(z\) for pickup.
  • Approach strategy: use 2–3 heights (above square, at grasp, lift) to avoid dragging pieces.
  • Branch selection: for each target, evaluate both elbow branches and pick the one that stays above the board and respects joint limits.
  • Later DOFs: wrist roll and gripper open/close can be layered on top; they do not change the position IK above.
