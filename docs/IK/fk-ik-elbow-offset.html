FK/IK with Elbow-Axis Offset \(dX\)

4‑DOF arm: base yaw \(q_0\) about \(+Z\), then shoulder/elbow/wrist pitch about parallel \(+Y\) axes. This page describes how the kinematics change if the elbow pitch axis is offset by a small distance \(dX\) in the arm plane along \(+X\) (when the shoulder link is upright, \(q_1=0\)).

1) What does “elbow axis offset by \(dX\)” mean?

In the ideal model, the shoulder→elbow segment is a single link of length \(L_1\) along the local \(+Z\) direction at \(q_1=0\). With an offset, the elbow pitch axis is not exactly at the end of that link; instead its position relative to the shoulder axis (in the shoulder’s local frame at \(q_1=0\)) is:

\[ \text{shoulder→elbow offset at }q_1=0:\quad \begin{bmatrix} dX \\ L_1 \end{bmatrix} \quad \text{in the }(r,z)\text{ plane} \]

Here \(r\) is the horizontal radial axis (in the yaw-reduced plane) and \(z\) is vertical. The elbow axis is still parallel to the shoulder axis (both are pitch axes along \(+Y\)), but its location has an extra in-plane translation.

This is a common “bracket/servo horn” effect. It is small but it changes IK: the arm is no longer a pure 2‑link triangle after removing \(L_3\).

2) FK with elbow offset \(dX\)

As usual, reduce 3D to the yaw plane:

\[ r=\sqrt{x^2+y^2},\qquad q_0=\operatorname{atan2}(y,x) \]

Define the shoulder→elbow contribution in the \((r,z)\) plane after rotating by \(q_1\) about \(+Y\). With the local offset \((dX, L_1)\) at \(q_1=0\), the rotated components are:

\[ r_{SE} = dX\cos(q_1) + L_1\sin(q_1) \]

\[ z_{SE} = -dX\sin(q_1) + L_1\cos(q_1) \]

Add the remaining links (same as the ideal planar model):

\[ r = r_{SE} + L_2\sin(q_1+q_2) + L_3\sin(q_1+q_2+q_3) \]

\[ z = H + z_{SE} + L_2\cos(q_1+q_2) + L_3\cos(q_1+q_2+q_3) \]

And convert back to \(x,y\):

\[ x=r\cos(q_0),\qquad y=r\sin(q_0) \]

FK with constrained tool pitch \(\gamma=\pi\)

If you enforce \(\gamma=q_1+q_2+q_3=\pi\), then \(\sin(\gamma)=0\), \(\cos(\gamma)=-1\), giving:

\[ r = dX\cos(q_1) + L_1\sin(q_1) + L_2\sin(q_1+q_2) \]

\[ z = H - L_3 - dX\sin(q_1) + L_1\cos(q_1) + L_2\cos(q_1+q_2) \]

3) IK implications

In the ideal model (no \(dX\)), after removing \(L_3\) you get a clean 2‑link triangle and can use the law of cosines. With \(dX\neq 0\), the shoulder contribution contains both \(\sin(q_1)\) and \(\cos(q_1)\) terms (because of the offset), so the simple law-of-cosines reduction no longer applies directly.

Practically: FK is still closed-form, but IK is best solved numerically (fast and robust for small offsets).

4) Recommended IK: numerical solve in the yaw-reduced plane

Choose a desired tool pitch \(\gamma\) (often constant for “downward” approach). After computing \(q_0\) and \(r\), compute the wrist point (end of \(L_2\)) by removing \(L_3\):

\[ r_w = r - L_3\sin(\gamma),\qquad z_w = (z-H) - L_3\cos(\gamma) \]

With elbow offset \(dX\), the wrist-point FK equations (unknowns \(q_1,q_2\)) are:

\[ f_r(q_1,q_2) = dX\cos(q_1) + L_1\sin(q_1) + L_2\sin(q_1+q_2) - r_w \]

\[ f_z(q_1,q_2) = -dX\sin(q_1) + L_1\cos(q_1) + L_2\cos(q_1+q_2) - z_w \]

Solve the 2×2 root-finding problem \(f_r=0,\ f_z=0\) using Newton or Levenberg–Marquardt. Once \(q_1,q_2\) are found, compute:

\[ q_3 = \gamma - q_1 - q_2 \]

Good initial guess

Use the closed-form IK that assumes \(dX=0\) as the initial guess \((q_1^{(0)},q_2^{(0)})\). For small \(dX\), Newton/LM typically converges in a few iterations.

Newton iteration (pseudocode)

# Unknowns: q1, q2 (radians)
# Goal: solve f(q1,q2) = [fr, fz] = [0,0]

for iter = 1..K:
  fr = dX*cos(q1) + L1*sin(q1) + L2*sin(q1+q2) - rw
  fz = -dX*sin(q1) + L1*cos(q1) + L2*cos(q1+q2) - zw

  # Jacobian J = df/d[q1,q2]
  dfr_dq1 = -dX*sin(q1) + L1*cos(q1) + L2*cos(q1+q2)
  dfr_dq2 =  L2*cos(q1+q2)
  dfz_dq1 = -dX*cos(q1) - L1*sin(q1) - L2*sin(q1+q2)
  dfz_dq2 = -L2*sin(q1+q2)

  Solve J * [dq1, dq2]^T = -[fr, fz]^T
  q1 += dq1
  q2 += dq2

Stop when sqrt(fr^2 + fz^2) is small.
If Newton is too sensitive near singularities, use Levenberg–Marquardt: solve \((J^T J + \lambda I)\Delta = -J^T f\) and adapt \(\lambda\).
