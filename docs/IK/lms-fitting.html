Least‑Squares (LM) Fit for Calibration Vector \(P\)

You collected \(N=50\) samples of commanded servo values \(u_i\) and measured positions \(x_i\). This page describes how to estimate a finite parameter vector \(P\) using nonlinear least squares (Levenberg–Marquardt).

DataResidualsJacobianLM

1) Define your calibration parameters \(P\)

A common 8‑parameter choice is per‑joint affine mapping (scale+offset):

\[ P = [s_1,s_2,s_3,s_4,\; o_1,o_2,o_3,o_4]^T \]

with

\[ \theta_j = s_j\,u_j + o_j \qquad (j=1..4) \]

If you strongly trust the scale (\(s_j\approx 1\)), you can fit offsets only: \(P=[o_1,o_2,o_3,o_4]\). Fewer parameters usually converges faster and is easier to identify.

2) Structure the dataset

For each measurement \(i=1..N\):

  • \(u_i = [u_{i1},u_{i2},u_{i3},u_{i4}]^T\) (servo commands you sent)
  • \(x_i = [X_i, Y_i, Z_i]^T\) (measured actual end‑effector position in base frame)

You do not need the “desired” \(x^{des}\) used to generate \(u_i\). Calibration uses command → measured.

3) Build the prediction model

Assume your link geometry is known. Implement forward kinematics:

\[ \hat{x} = FK(\theta) \]

Compose it with the servo→angle mapping:

\[ \hat{x}_i(P) = FK(\theta(u_i, P)) \]

4) Define residuals and stack them into one vector

Residual for each sample:

\[ r_i(P) = \hat{x}_i(P) - x_i \in \mathbb{R}^3 \]

Stack all residuals into a single vector \(r(P)\in \mathbb{R}^{3N}\):

\[ r(P) = \begin{bmatrix} r_1(P) \\ r_2(P) \\ \vdots \\ r_N(P) \end{bmatrix} \]

Objective (sum of squared errors):

\[ P^\* = \arg\min_P \lVert r(P)\rVert^2 \]

5) Initialize \(P_0\) (this matters)

  • Typical start: \(s_j = 1\) for all joints
  • Offsets \(o_j\): your best guess from mechanical “home” tuning (or 0 if unknown)
If angles are in radians internally but your servo commands \(u\) are “degrees-like”, make sure \(s_j\) is initialized to the correct conversion factor. Bad unit assumptions will look like “LM doesn’t converge”.

6) Solve using Levenberg–Marquardt (LM)

LM minimizes \(\lVert r(P)\rVert^2\) by iteratively linearizing around the current \(P\).

Jacobian

Compute the Jacobian \(J(P) = \frac{\partial r}{\partial P} \in \mathbb{R}^{3N \times 8}\).

  • Numerical (finite differences): easiest, often sufficient for 8 params.
  • Analytical: faster and more stable if you derive \(\partial FK / \partial \theta\) and chain rule through \(\theta(u,P)\).

LM update equation

Solve for \(\Delta P\):

\[ (J^T J + \lambda I)\,\Delta P = -J^T r \]

Then update:

\[ P \leftarrow P + \Delta P \]

\(\lambda\) is adjusted: if the step reduces error, decrease \(\lambda\); otherwise increase \(\lambda\) and retry (this is the standard LM trust-region behavior).

7) Practical checks (so you know it worked)

  1. Hold-out validation: fit on ~80% of samples, report RMS error on remaining 20%.
  2. RMS error: \[ \mathrm{RMS} = \sqrt{\frac{1}{N}\sum_{i=1}^{N} \lVert r_i(P^\*)\rVert^2} \]
  3. Per-axis RMS: compute RMS on X/Y/Z separately to see if one axis dominates.
  4. Outliers: if a few points are bad touches, consider a robust loss (Huber) or drop obvious outliers.

8) How you use \(P^\*\) (no target pre-warp)

Use the calibrated mapping inside your IK/FK pipeline:

  • When solving IK for a desired position, solve for physical angles \(\theta\) using your calibrated model.
  • Convert \(\theta \rightarrow u\) using the inverse affine mapping: \[ u_j = \frac{\theta_j - o_j}{s_j} \]
Conceptually: your robot model becomes “FK/IK + calibrated servo mapping”. You don’t alter the target \(x\); you alter the model that interprets servo values.

Minimal pseudocode

Given data: (u_i, x_i) for i=1..N
Choose parameterization P (8 params or 4 offsets)
Initialize P = P0
Repeat until convergence:
  r = []
  for i in 1..N:
    theta = theta_from_servo(u_i, P)        # theta_j = s_j*u_j + o_j
    x_hat = FK(theta)                       # predicted position
    r.append(x_hat - x_i)                   # 3-vector
  J = jacobian_of_r_wrt_P(P)                # numeric or analytic
  Solve (J^T J + λ I) ΔP = -J^T r
  If ||r(P + ΔP)|| < ||r(P)||:
     P = P + ΔP; decrease λ
  else:
     increase λ and retry
Return P*

Implementation hint: if you want a ready-made solver, use a standard LM least-squares library (e.g., SciPy’s least_squares, Ceres Solver, g2o).
