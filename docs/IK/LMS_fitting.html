LMS/LM fitting: calibrate from \(\{Q^{cmd}_i, X^{meas}_i\}\)

Step-by-step: how to fit correction parameters with least squares / Levenberg–Marquardt (LM), using your 20–50 experiments where you logged the commanded joint angles \(Q^{cmd}\) and measured TCP positions \(X^{meas}\).

0) Units and notation (match your code)

  • Angles in degrees in logs/config. Convert to radians inside \(\sin,\cos\) for FK.
  • Positions in millimeters.
  • Sample \(i\) contains: \[ Q^{cmd}_i = [q_{0},q_{1},q_{2},q_{3}]_i \in \mathbb{R}^4,\qquad X^{meas}_i = [x,y,z]_i \in \mathbb{R}^3 \]
You can compute an “\(X^{pred}\)” from \(Q^{cmd}\) using your current FK, but in calibration \(X^{pred}\) depends on the unknown parameters you are fitting. So treat \(X^{pred}_i(P)\) as a function of the parameter vector \(P\), not a fixed value.

1) Choose what to fit (start simple)

Stage A (recommended first): fit per-joint angle offsets only

Fit only 4 parameters \(b_j\) (degrees):

\[ b = [b_0,b_1,b_2,b_3]^T \]

Model:

\[ q^{phys}_{i,j} = q^{cmd}_{i,j} + b_j \]

Stage B (optional): fit scale + offset per joint

If you still see systematic “too short/too long” behavior across the whole range, unlock per-joint scales \(a_j\):

\[ a = [a_0,a_1,a_2,a_3]^T,\qquad b = [b_0,b_1,b_2,b_3]^T \]

\[ q^{phys}_{i,j} = a_j\,q^{cmd}_{i,j} + b_j \]

Don’t fit \(a\) and link lengths at the same time initially. They can “trade off” and make the optimization ill-conditioned unless you add strong priors.

2) Define the prediction model \(X^{pred}_i(P)\)

For a candidate parameter vector \(P\) (either \(b\) only, or \((a,b)\)), compute:

\[ Q^{phys}_i(P) = [q^{phys}_{i,0}, q^{phys}_{i,1}, q^{phys}_{i,2}, q^{phys}_{i,3}] \]

Then predict TCP position with forward kinematics:

\[ X^{pred}_i(P) = FK\!\left(Q^{phys}_i(P);\;H,L_1,L_2,L_3,dX\right) \]

Use the exact FK you currently run in JS (including \(dX\) if enabled). Calibration will only be as good as the model you fit.

3) Residuals and objective (least squares)

Residual for sample \(i\):

\[ r_i(P) = X^{pred}_i(P) - X^{meas}_i \in \mathbb{R}^3 \]

Stack all residuals into one vector \(r(P)\in\mathbb{R}^{3N}\) and minimize the sum of squares:

\[ P^\* = \arg\min_P \sum_{i=1}^{N}\lVert r_i(P)\rVert^2 \]

4) LM/LMS update rule (what “LMS fitting” does)

Let \(J(P) = \frac{\partial r}{\partial P}\) be the Jacobian of the stacked residual vector. LM solves for an update \(\Delta P\) via:

\[ (J^T J + \lambda I)\,\Delta P = -J^T r \]

Then:

\[ P \leftarrow P + \Delta P \]

Adapt \(\lambda\): if the error decreases, reduce \(\lambda\); otherwise increase \(\lambda\) and retry.

You usually do numerical Jacobians first (finite differences). Analytical Jacobians are faster but optional.

5) MATLAB implementation (recommended: lsqnonlin)

If you have Optimization Toolbox, lsqnonlin runs LM/TR solvers for you. You provide only a residual function that returns the stacked \(3N\) vector.

Data layout

% Qcmd: N×4 (deg)
% Xmeas: N×3 (mm)
% geom: struct with H,L1,L2,L3,dX (mm)

Stage A residual (fit b only)

function r = residual_b_only(b, Qcmd, Xmeas, geom)
% b: 4×1 (deg)
N = size(Qcmd,1);
r = zeros(3*N,1);
for i = 1:N
  Qphys = Qcmd(i,:)' + b;              % 4×1 (deg)
  Xpred = FK_deg(Qphys, geom);         % 3×1 (mm), FK converts deg→rad internally
  ri = Xpred - Xmeas(i,:)';            % 3×1
  r(3*(i-1)+1:3*i) = ri;
end
end

Stage B residual (fit a and b)

function r = residual_a_b(P, Qcmd, Xmeas, geom)
% P: 8×1 where a=P(1:4), b=P(5:8)
a = P(1:4);
b = P(5:8);
N = size(Qcmd,1);
r = zeros(3*N,1);
for i = 1:N
  Qphys = a .* Qcmd(i,:)' + b;         % 4×1 (deg)
  Xpred = FK_deg(Qphys, geom);         % 3×1 (mm)
  ri = Xpred - Xmeas(i,:)';
  r(3*(i-1)+1:3*i) = ri;
end
end

Calling lsqnonlin

% Stage A: fit offsets only
b0 = zeros(4,1);
opts = optimoptions('lsqnonlin', 'Display','iter', 'MaxFunctionEvaluations', 1e5);
b_star = lsqnonlin(@(b)residual_b_only(b, Qcmd, Xmeas, geom), b0, [], [], opts);

% Stage B: unlock scales too (optional)
P0 = [ones(4,1); b_star];
lb = [0.9*ones(4,1); -20*ones(4,1)];   % example bounds
ub = [1.1*ones(4,1);  20*ones(4,1)];
P_star = lsqnonlin(@(P)residual_a_b(P, Qcmd, Xmeas, geom), P0, lb, ub, opts);
a_star = P_star(1:4);
b_star = P_star(5:8);
If you don’t have Optimization Toolbox, you can still implement LM using the equation \((J^T J + \lambda I)\Delta=-J^T r\) with a numerical Jacobian.

6) What to do with the fitted parameters

After you obtain \((a^\*, b^\*)\), apply them in the control path (IK → pulses):

\[ q^{tbl}=\frac{q^{cmd}-b^\*}{a^\*} \]

Then compute pulses from calPoints using \(q^{tbl}\).

If you fitted offsets only, use \(a^\*=1\) and \(q^{tbl}=q^{cmd}-b^\*\).

7) Sanity checks

  • Hold-out validation: fit on ~80% points, report RMS on remaining ~20%.
  • RMS error: \[ \mathrm{RMS}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}\|r_i(P^\*)\|^2} \]
  • Branch consistency: if you enforce elbow-up only, make sure all samples used the same branch logic.
  • Data diversity: vary base yaw, shoulder/elbow/wrist, and height; avoid all points lying on one plane.
