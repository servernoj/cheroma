XY-only fitting (practice run)

This is the “practice” calibration setup where you do not measure Z at all. You use a laser + printed grid to measure \((x,y)\) precisely, and you fit only the parameters that improve XY. No \(c_z\) and no \(z^{meas}\) are used.

1) What you log

  • \(Q^{cmd}_i = [q_0,q_1,q_2]_i\) in degrees (the joint angles you commanded for the final pose).
  • \(X^{meas}_{i,xy} = [x,y]_i\) in mm (measured from the printed grid).
You can still execute a 3-step motion (reset → approach \(z+100\) → descend). Just make sure you measure \((x,y)\) only at the final pose.

2) What you fit

Stage A: offsets only

Fit:

\[ b=[b_0,b_1,b_2]^T \]

Model:

\[ q^{phys}_{i,j} = q^{cmd}_{i,j} + b_j \]

Stage B (optional): scales + offsets

Fit:

\[ a=[a_0,a_1,a_2]^T,\qquad b=[b_0,b_1,b_2]^T \]

Model:

\[ q^{phys}_{i,j} = a_j\,q^{cmd}_{i,j} + b_j \]

Keep \(a\) tightly bounded near 1 (e.g. 0.98–1.02). If \(a_0\) tries to drift, it often indicates an XY registration issue.

3) Residuals (XY only)

For each sample \(i\), compute:

\[ X^{pred}_i(P)=FK\!\left(Q^{phys}_i(P)\right) = [x^{pred}_i,y^{pred}_i,z^{pred}_i]^T \]

Then define a 2D residual (ignore Z):

\[ r_i(P)= \begin{bmatrix} x^{pred}_i(P) - x^{meas}_i\\ y^{pred}_i(P) - y^{meas}_i \end{bmatrix} \]

Stack all residuals into \(r(P)\in\mathbb{R}^{2N}\) and minimize \(\|r(P)\|^2\) with LM (lsqnonlin).

4) Full MATLAB code (XY-only)

Inputs:

  • Qcmd: \(N\times 3\) in degrees \([q0,q1,q2]\)
  • XYmeas: \(N\times 2\) in mm \([x,y]\)
function out = xy_fitting(Qcmd, XYmeas)
% Qcmd: N×3 (deg) [q0,q1,q2]
% XYmeas: N×2 (mm) [x,y]

  opts = optimoptions('lsqnonlin', 'Display','iter', 'MaxFunctionEvaluations', 1e5);

  % -------- Stage A: offsets only
  b0 = zeros(3,1);
  b_star = lsqnonlin(@(b)residual_xy_b_only(b, Qcmd, XYmeas), b0, [], [], opts);
  out.stageA.b = b_star;

  % -------- Stage B (optional): scales + offsets
  doStageB = true;
  if doStageB
    P0 = [ones(3,1); b_star];             % P=[a;b]
    lb = [0.98*ones(3,1); -20*ones(3,1)];
    ub = [1.02*ones(3,1);  20*ones(3,1)];
    P_star = lsqnonlin(@(P)residual_xy_a_b(P, Qcmd, XYmeas), P0, lb, ub, opts);
    out.stageB.a = P_star(1:3);
    out.stageB.b = P_star(4:6);
  end
end

function r = residual_xy_b_only(b, Qcmd, XYmeas)
% b: 3×1 for [q0,q1,q2] offsets in degrees
  N = size(Qcmd,1);
  r = zeros(2*N,1);
  for i = 1:N
    Qphys = Qcmd(i,:)' + b;           % 3×1 (deg)
    Xpred = FK_deg_gamma_pi(Qphys);   % 3×1 (mm)
    ri = [Xpred(1) - XYmeas(i,1);
          Xpred(2) - XYmeas(i,2)];
    r(2*(i-1)+1:2*i) = ri;
  end
end

function r = residual_xy_a_b(P, Qcmd, XYmeas)
% P: 6×1 where a=P(1:3), b=P(4:6)
  a = P(1:3);
  b = P(4:6);
  N = size(Qcmd,1);
  r = zeros(2*N,1);
  for i = 1:N
    Qphys = a .* Qcmd(i,:)' + b;      % 3×1 (deg)
    Xpred = FK_deg_gamma_pi(Qphys);   % 3×1 (mm)
    ri = [Xpred(1) - XYmeas(i,1);
          Xpred(2) - XYmeas(i,2)];
    r(2*(i-1)+1:2*i) = ri;
  end
end

function X = FK_deg_gamma_pi(Q)
% FK for gamma = pi case, using q0,q1,q2 in degrees.
% Replace these constants with your current model values.
  q0 = Q(1); q1 = Q(2); q2 = Q(3);

  H  = 130;
  L1 = 211;
  L2 = 265;
  L3 = 112;
  dX = 20;

  r = (dX*cosd(q1) + L1*sind(q1)) + L2*sind(q1 + q2);
  z = H - L3 - dX*sind(q1) + L1*cosd(q1) + L2*cosd(q1 + q2); %#ok

  x = r*cosd(q0);
  y = r*sind(q0);

  X = [x; y; z];
end
After fitting, apply the resulting corrections in your control pipeline as described in your other docs: in runtime you typically convert \(q^{cmd}\rightarrow q^{tbl}\) before looking up pulses from calPoints.
