Option A: Fit Z using a known plane (no per-point Z measurement)

Use this when you can measure \(x,y\) accurately (laser on a printed grid) but \(z\) is hard to measure per point. You will collect all points on a single plane (paper) and fit a single Z correction parameter \(c_z\).

1) Experiment design

  • Keep the TCP/laser dot on the paper plane for all measurements.
  • Use the same approach strategy (your 3-step move) so mechanical backlash is consistent.
  • Log \(Q^{cmd}_i=[q_0,q_1,q_2]_i\) (deg) and \(X^{meas}_{i,xy}=[x,y]_i\) (mm) from the grid.
  • Choose a known plane height \(z_{plane}\) for the session and set \(z^{meas}_i = z_{plane}\) for all samples in that session.
You do not need to know \(z_{plane}\) perfectly. Any constant offset between your “paper plane” and the model’s Z reference is exactly what the fitted \(c_z\) will capture.

2) Model: add one Z bias parameter \(c_z\)

Let \(FK(\cdot)\) be your current forward kinematics that predicts \(X^{pred}=[x^{pred},y^{pred},z^{pred}]\). Add a single parameter \(c_z\) (mm) that shifts the predicted Z:

\[ z^{pred} \leftarrow z^{pred} + c_z \]

This is equivalent to fitting a correction to the constant term \((H-L_3)\) in your \(\gamma=\pi\) FK.

3) What to fit

Stage A: offsets + Z bias

Fit:

\[ P = [b_0,b_1,b_2,c_z]^T \]

with:

\[ q^{phys}_{i,j} = q^{cmd}_{i,j} + b_j \]

Stage B (optional): scales + offsets + Z bias

If you still see proportional error with angle magnitude, fit:

\[ P = [a_0,a_1,a_2,b_0,b_1,b_2,c_z]^T \]

with:

\[ q^{phys}_{i,j} = a_j\,q^{cmd}_{i,j} + b_j \]

Keep \(a_j\) tightly bounded near 1 (e.g. 0.98–1.02). If \(a_0\) wants to drift, it often indicates XY frame/registration issues.

4) Residuals (what LM minimizes)

For each sample \(i\), define:

\[ r_i(P) = \begin{bmatrix} x^{pred}_i(P) - x^{meas}_i \\ y^{pred}_i(P) - y^{meas}_i \\ (z^{pred}_i(P)+c_z) - z^{meas}_i \end{bmatrix} \]

Stack all residuals into \(r(P)\in\mathbb{R}^{3N}\) and minimize \(\|r(P)\|^2\) with LM (lsqnonlin).

5) Full MATLAB code (offsets-only + Z bias, then optional scale+offset)

This is a complete single-file example. Replace the geometry values with your current measured values. Inputs:

  • Qcmd: \(N\times 3\) in degrees \([q0,q1,q2]\)
  • Xmeas: \(N\times 3\) in mm \([x,y,z]\)
To combine multiple “runs” at different plane heights, just concatenate rows: Qcmd_all = [Qcmd_run1; Qcmd_run2; Qcmd_run3], Xmeas_all = [Xmeas_run1; Xmeas_run2; Xmeas_run3], where each Xmeas_runK(:,3) is filled with that run’s chosen \(z_{plane}\). 
function out = z_fitting(Qcmd, Xmeas)
% Qcmd: N×3 (deg) [q0,q1,q2]
% Xmeas: N×3 (mm) [x,y,z]
%
% Output:
% out.stageA: fitted [b0;b1;b2;cz]
% out.stageB: fitted [a0;a1;a2;b0;b1;b2;cz] (optional)

  opts = optimoptions('lsqnonlin', 'Display','iter', 'MaxFunctionEvaluations', 1e5);

  % -------- Stage A: offsets + cz
  P0 = zeros(4,1);  % [b0;b1;b2;cz]
  P_A = lsqnonlin(@(P)residual_b_cz(P, Qcmd, Xmeas), P0, [], [], opts);

  out.stageA.b = P_A(1:3);
  out.stageA.cz = P_A(4);
  out.stageA.P = P_A;

  % -------- Stage B (optional): scales + offsets + cz
  doStageB = true;
  if doStageB
    a0 = ones(3,1);
    P0b = [a0; out.stageA.b; out.stageA.cz];  % [a0;a1;a2;b0;b1;b2;cz]

    lb = [0.98*ones(3,1); -20*ones(3,1); -50];
    ub = [1.02*ones(3,1);  20*ones(3,1);  50];

    P_B = lsqnonlin(@(P)residual_a_b_cz(P, Qcmd, Xmeas), P0b, lb, ub, opts);
    out.stageB.a = P_B(1:3);
    out.stageB.b = P_B(4:6);
    out.stageB.cz = P_B(7);
    out.stageB.P = P_B;
  end
end

function r = residual_b_cz(P, Qcmd, Xmeas)
% P = [b0;b1;b2;cz]
  b = P(1:3);
  cz = P(4);

  N = size(Qcmd,1);
  r = zeros(3*N,1);
  for i = 1:N
    Qphys = Qcmd(i,:)' + b;         % 3×1 (deg)
    Xpred = FK_deg_gamma_pi(Qphys); % 3×1 (mm)
    ri = [Xpred(1) - Xmeas(i,1);
          Xpred(2) - Xmeas(i,2);
          (Xpred(3) + cz) - Xmeas(i,3)];
    r(3*(i-1)+1:3*i) = ri;
  end
end

function r = residual_a_b_cz(P, Qcmd, Xmeas)
% P = [a0;a1;a2;b0;b1;b2;cz]
  a = P(1:3);
  b = P(4:6);
  cz = P(7);

  N = size(Qcmd,1);
  r = zeros(3*N,1);
  for i = 1:N
    Qphys = a .* Qcmd(i,:)' + b;    % 3×1 (deg)
    Xpred = FK_deg_gamma_pi(Qphys); % 3×1 (mm)
    ri = [Xpred(1) - Xmeas(i,1);
          Xpred(2) - Xmeas(i,2);
          (Xpred(3) + cz) - Xmeas(i,3)];
    r(3*(i-1)+1:3*i) = ri;
  end
end

function X = FK_deg_gamma_pi(Q)
% FK for gamma = pi case, using q0,q1,q2 in degrees.
% Replace these constants with your current model values.
  q0 = Q(1); q1 = Q(2); q2 = Q(3);

  H  = 130;
  L1 = 211;
  L2 = 265;
  L3 = 112;
  dX = 20;

  r = (dX*cosd(q1) + L1*sind(q1)) + L2*sind(q1 + q2);
  z = H - L3 - dX*sind(q1) + L1*cosd(q1) + L2*cosd(q1 + q2);

  x = r*cosd(q0);
  y = r*sind(q0);

  X = [x; y; z];
end
This formulation already supports multiple plane heights: just populate Xmeas(:,3) per sample with that run’s plane height. If you later suspect the board is tilted, a next step is to fit a plane \(z=ax+by+c\) instead of using fixed \(z^{meas}_i\).
