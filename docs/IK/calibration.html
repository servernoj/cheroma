Frames & units

  • Base frame \(B\): origin on the base yaw axis. \(Z_B\) points up; base rotation is about \(Z_B\).
  • Board frame \(C\): \(X_C\) along files (A→H), \(Y_C\) along ranks (1→8), \(Z_C\) is board normal (up).
  • Units: use millimeters for all positions/lengths (FK, IK, board), and radians (or degrees) for angles—just be consistent.
You can keep a repeatable “home/reference pose” \(q_0\) (servo values) for startup and IK branch selection; it’s not required to redefine the base frame origin.

Kinematic model (FK/IK)

Let \(u = [u_1,u_2,u_3,u_4]^T\) be the commanded servo values (e.g., degrees or PWM-mapped degrees). Let \(\theta = [\theta_1,\theta_2,\theta_3,\theta_4]^T\) be the physical joint angles used by FK/IK.

Servo command → joint angle mapping (calibration parameters)

A practical affine model per joint:

\[ \theta_j = s_j\,u_j + o_j \quad \text{for } j=1..4 \]

  • \(o_j\): joint “zero” offset (mechanical mounting bias)
  • \(s_j\): scale (e.g., true degrees per commanded degree); often close to 1

Forward kinematics (FK)

With known link geometry, FK maps joint angles to end-effector position (or pose) in base frame:

\[ \hat{x} = FK(\theta) \in \mathbb{R}^3 \]

IK decomposition for “base yaw + planar arm”

For a desired position \(x=[X,Y,Z]^T\) in base frame:

\[ \theta_1 = \operatorname{atan2}(Y,X) \quad,\quad r = \sqrt{X^2 + Y^2} \]

Then solve a planar IK in the \((r,Z)\) plane for \(\theta_2,\theta_3,\theta_4\) (your exact equations depend on where the wrist/TCP is defined and link layout).

Robot calibration as finite parameter estimation

Collect \(N\) measurements. For each measurement \(i\):

  • Command the robot with servo values \(u_i\).
  • Measure the resulting end-effector position \(x_i \in \mathbb{R}^3\) in base frame (or in a known frame you can convert to base).

Choose a finite parameter vector

Example: offsets+scales only:

\[ p = [s_1,s_2,s_3,s_4,o_1,o_2,o_3,o_4]^T \]

Optional additions (still finite): TCP offset (3 params), uncertain link lengths, base-to-shoulder height offset, etc.

Prediction and residuals

Predicted position for measurement \(i\):

\[ \hat{x}_i(p) = FK(\theta(u_i,p)) \]

Residual:

\[ r_i(p) = \hat{x}_i(p) - x_i \]

Least squares objective (solve once, then reuse)

\[ p^\* = \arg\min_p \sum_{i=1}^{N} \lVert r_i(p)\rVert^2 \]

This is generally a nonlinear least-squares problem; solve with Levenberg–Marquardt (LM). You typically want overdetermined data (e.g., 20–50 diverse poses) for stability.

Recommended usage
After you fit \(p^\*\), run IK using the calibrated mapping \(\theta(u,p^\*)\) (or equivalently adjust IK’s joint zero/scale). You do not need to “pre-warp” targets \(x\) if your IK uses the calibrated model.
If you only have planar touches
If your measurements provide only \(X,Y\) (board plane) and not \(Z\), you can still fit parameters, but some may become weakly observable. Prefer collecting points that vary \(r\) and \(Z\) (and multiple base angles).

If you insist on “target pre-warp” (optional wrapper)

If you want to keep a fixed nominal IK and instead convert a target \(x\) into a compensated command target \(x_{\text{cmd}}\), define:

\[ h(x) = FK(\theta(IK_{\text{nom}}(x),p^\*)) \quad (\text{predicted actual position if you command nominal IK}) \]

Find \(x_{\text{cmd}}\) such that \(h(x_{\text{cmd}})=x_{\text{target}}\) via iteration: 

Initialize x_cmd = x_target
Repeat K times:
  u = IK_nom(x_cmd)
  x_hat = FK(theta(u, p*))
  e = x_hat - x_target
  x_cmd = x_cmd - e
Command u = IK_nom(x_cmd)

This works when errors are small and smooth, but using a calibrated IK is usually cleaner and more reliable.

Chessboard registration (board → base)

Create a mapping from chessboard coordinates to base coordinates using a rigid transform plus square size. The simplest: touch a few known squares with a repeatable pointer.

Board coordinates

Let square size be \(s\) (mm). Represent square centers in board frame \(C\) as:

\[ x_C(f,r) = \begin{bmatrix} (f+0.5)\,s \\ (r+0.5)\,s \\ 0 \end{bmatrix} \quad \text{where } f\in\{0..7\} \text{ is file (A..H), } r\in\{0..7\} \text{ is rank (1..8).} \]

Minimal 3-point registration on a level board

Touch centers of A1, H1, A8 and measure their base-frame positions: \(p_{A1}, p_{H1}, p_{A8} \in \mathbb{R}^3\).

Define unit axes (in base frame):

\[ \hat{e}_x = \frac{p_{H1}-p_{A1}}{\lVert p_{H1}-p_{A1}\rVert} \quad,\quad \hat{e}_y = \frac{p_{A8}-p_{A1}}{\lVert p_{A8}-p_{A1}\rVert} \quad,\quad \hat{e}_z = \hat{e}_x \times \hat{e}_y \]

Enforce orthonormality (optional but recommended): re-orthogonalize \(\hat{e}_y \leftarrow \hat{e}_z \times \hat{e}_x\), normalize.

Square size:

\[ s \approx \frac{\lVert p_{H1}-p_{A1}\rVert}{7} \quad\text{and/or}\quad s \approx \frac{\lVert p_{A8}-p_{A1}\rVert}{7} \]

Rotation matrix \(R_B^C\) and translation \(t_B^C\):

\[ R_B^C = \begin{bmatrix} \hat{e}_x & \hat{e}_y & \hat{e}_z \end{bmatrix} \quad,\quad t_B^C = p_{A1} \]

Then board point in base:

\[ x_B = R_B^C\,x_C + t_B^C \]

Robust registration (recommended)

Touch \(M\) square centers across the board (corners + mid edges + some interior). Fit:

  • a best-fit plane (if board isn’t perfectly level),
  • a rigid transform \(R_B^C, t_B^C\),
  • square size \(s\) (optionally).

In practice, you minimize \(\sum_k \| R_B^C x_{C,k}(s) + t_B^C - p_{B,k}\|^2\) over \(R,t,s\) (with \(R\in SO(3)\)).

End‑to‑end pipeline (square → servo commands)

  1. Square → board point: pick file/rank \((f,r)\), choose square size \(s\), compute \(x_C(f,r)\).
  2. Board → base: \(x_B = R_B^C\,x_C + t_B^C\). Add Z heights for approach/grasp/drop as needed.
  3. Base point → joint angles: \(\theta = IK(x_B, p^\*)\) (IK uses calibrated offsets/scales).
  4. Joint angles → servo values: \(u\) from \(\theta\) using inverse of \(\theta_j=s_j u_j + o_j\), i.e. \[ u_j = \frac{\theta_j - o_j}{s_j} \]
Practical: always approach touch/grasp points from the same direction (backlash), and ensure a repeatable startup/home routine.
