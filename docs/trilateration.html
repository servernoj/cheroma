1. Baseline frame

Attach a local frame to the two anchors:

$$\mathbf{u} = \frac{A_1 - A_2}{\lVert A_1 - A_2 \rVert}, \qquad L = \lVert A_1 - A_2 \rVert, \qquad \mathbf{v} = \pm\,(\mathbf{u} \times \hat{\mathbf{z}}).$$

$\mathbf{u}$ runs from $A_2$ to $A_1$ along the baseline; $\mathbf{v}$ is the in-plane unit vector perpendicular to $\mathbf{u}$. The sign of $\mathbf{v}$ resolves the mirror ambiguity (which side of the baseline the POI lies on).

2. Parameterize the POI on the anchor plane

Write the foot of the POI on the anchor plane as $F = A_2 + s\,\mathbf{u} + n\,\mathbf{v}$. The two measured horizontal distances give

$$d_2^{\,2} = s^{2} + n^{2}, \qquad d_1^{\,2} = (s - L)^{2} + n^{2}.$$

Subtracting eliminates $n$:

$$d_2^{\,2} - d_1^{\,2} = s^{2} - (s-L)^{2} = 2\,L\,s - L^{2} \;\;\Longrightarrow\;\; \boxed{\;s = \dfrac{d_2^{\,2} - d_1^{\,2} + L^{2}}{2\,L}\;}$$

and back-substituting gives the altitude:

$$\boxed{\;n = \sqrt{\,d_2^{\,2} - s^{2}\,}\;}$$

Finally,

$$F = A_2 + s\,\mathbf{u}, \qquad \text{POI} = F + n\,\mathbf{v} + h\,\hat{\mathbf{z}}.$$

3. Error sensitivity

Assuming independent Gaussian errors $\sigma_d$ on both distance readings, first-order propagation gives

$$\sigma_s = \dfrac{\sqrt{d_1^{\,2} + d_2^{\,2}}}{L}\,\sigma_d, \qquad \sigma_n = \dfrac{\sqrt{d_1^{\,2}\,s^{2} + d_2^{\,2}\,(L-s)^{2}}}{L\,n}\,\sigma_d.$$

The only way $\sigma_n$ blows up is $n \to 0$, i.e., when the POI approaches the line through $A_1$ and $A_2$. Keep the POI away from the extended baseline and the geometry is well-conditioned.

4. Reference implementation

The live panel above runs this exact procedure in JavaScript; the same logic in Python:

import numpy as np

def trilaterate(A1, A2, d1, d2, h=0.0, side=+1):
    A1 = np.asarray(A1, float); A2 = np.asarray(A2, float)
    L  = np.linalg.norm(A1 - A2)
    u  = (A1 - A2) / L
    v  = side * np.cross(u, [0, 0, 1])          # right of A2→A1 when side=+1
    s  = (d2**2 - d1**2 + L**2) / (2*L)
    n  = np.sqrt(max(d2**2 - s**2, 0.0))
    foot = A2 + s*u
    poi  = foot + n*v + np.array([0, 0, h])
    return poi, foot, n
