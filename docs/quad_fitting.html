Quadratic Joint Correction – Inversion

1. Forward model

The quadratic joint correction maps commanded angles to actual angles:

$$Q_{\text{act}} = c_2 \cdot Q_{\text{cmd}}^{\,2} + a \cdot Q_{\text{cmd}} + b$$

2. Inversion problem

Given a desired angle $Q_{\text{des}}$, find $Q_{\text{cmd}}$ such that $Q_{\text{act}} = Q_{\text{des}}$:

$$c_2 \cdot Q_{\text{cmd}}^{\,2} + a \cdot Q_{\text{cmd}} + (b - Q_{\text{des}}) = 0$$

3. Quadratic formula

Discriminant:

$$d = a^2 - 4\,c_2\,(b - Q_{\text{des}}) = a^2 + 4\,c_2\,(Q_{\text{des}} - b)$$

The physically meaningful root (the one near the linear solution):

$$Q_{\text{cmd}} = \frac{-a + \sqrt{d}}{2\,c_2}$$

4. Numerically stable form

When $c_2$ is small, the formula above suffers from catastrophic cancellation ($-a + \sqrt{d}$ subtracts two nearly equal values). Multiplying numerator and denominator by the conjugate:

$$\frac{-a + \sqrt{d}}{2\,c_2} = \frac{(-a + \sqrt{d})(a + \sqrt{d})}{2\,c_2\,(a + \sqrt{d})} = \frac{d - a^2}{2\,c_2\,(a + \sqrt{d})} = \frac{4\,c_2\,(Q_{\text{des}} - b)}{2\,c_2\,(a + \sqrt{d})}$$

which simplifies to:

$$\boxed{\;Q_{\text{cmd}} = \frac{2\,(Q_{\text{des}} - b)}{a + \sqrt{a^2 + 4\,c_2\,(Q_{\text{des}} - b)}}\;}$$

5. Graceful fallback to linear

When $c_2 = 0$:

$$Q_{\text{cmd}} = \frac{2\,(Q_{\text{des}} - b)}{a + \sqrt{a^2}} = \frac{2\,(Q_{\text{des}} - b)}{a + a} = \frac{Q_{\text{des}} - b}{a}$$

This is exactly the current linear inversion formula.
